# Monster Taimer – Heldenzimmer V0.3 (ENTWURF)

## Stand
- Eigenständiger Prototyp auf einem separaten Entwicklungsbranch, keine Änderung des bestehenden Hauptstands
- Startszene: Zimmer des Helden, 48 × 32 logische Kacheln (32 Pixel)
- Steuerung: iPhone-Joystick, A/B, Select/Start sowie Tastatur
- Möbel und Wände: logische Kollisionszonen
- Treppe unten rechts: Ausgang zur bestehenden Fjordsiedlung
- Von dort besteht der bisherige Übergang in den Nebelwald
- Originalzimmermotiv mit Wolfsteppich: vom Nutzer im Chat bestätigt; **Bilddatei noch nicht in GitHub hochgeladen**

## Bildintegration (ausstehend)
Das freigegebene Originalbild muss unverändert unter
`monster-taimer/hero-room-v03/assets/hero-room-wolf.png`
in diesen Entwicklungsbranch hochgeladen werden. Das HTML lädt die Datei beim Start.

Es wurde kein Artwork heimlich ersetzt und keine Kanonversion überschrieben.

## Kollisionskoordinaten
Referenzmaß: 1536 × 1024 Pixel, 48 × 32 Kacheln. Fest codierte Zonen für Schreibtisch,
Fensterwand, TV, Bett, Sofa, Tisch, Regal und Treppenbereich. Die Positionen sind vorläufig
und nach Originalbildimport auf optisch korrekte Freigängigkeit zu testen.
