# Monsters of Midgard

Eigenständiges 2D-Rollenspielprojekt. Dieses Repository ist ausschließlich für **Monsters of Midgard** bestimmt; keine Übernahme von Dateien oder Regeln aus Etarium oder anderen Projekten.

## Entwicklungsstand

- **Heldenhaus / Oberwelt:** zuletzt im Chat bereitgestellte Ausgangsfassung **V23** als eigenständige HTML-Demo (noch **nicht** im Repository gespeichert).
- Es existierte eine spätere **V24** mit Anpassungen der Treppengeländer-Überdeckung. Die vollständige V24-Datei wird erst nach sicherem Zugriff und Prüfung übernommen.
- Aktuelle Priorität: visuelle Kollisionen und frei begehbare Laufwege auf **beiden Etagen**, korrekte Figuren-/Möbel-Tiefensortierung, Geländer beim Treppenauf- und -abstieg.
- Die iPhone-Hochformat-Steuerung und bestehenden Dialog-/Interaktionsfunktionen sollen unverändert bleiben.

## Vorgehen

1. Original-HTML sicher als Quellstand ablegen und mit Prüfsumme dokumentieren.
2. Treppen-/Geländermaske und Bewegungsübergänge überprüfen.
3. Kollisionspolygone an Möbelstandflächen statt visuellen Überhängen ausrichten.
4. Laufweg-/Interaktionsprüfungen für beide Etagen automatisieren.
5. Auf einem iPhone praktisch testen; ein Syntaxcheck allein ist kein Gameplaytest.

**Hinweis:** Die HTML-Demo enthält eingebettete Ressourcen und ist groß. Vor einem öffentlichen Upload müssen Nutzungsrechte und die GitHub-Dateigrößenlimits geprüft werden. Es wurden bislang keine Bilder, ROMs oder Spielassets in dieses Repository hochgeladen.
